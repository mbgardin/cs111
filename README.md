Welcome to my repository for **CS111: Introduction to Computer Science** at Brigham Young University. This course provided a rigorous foundation in programming, computational thinking, and software design using Python.

This repository serves as a portfolio of my work, showcasing my ability to solve complex problems, build functional applications, and apply computer science principles in a practical setting.

## 🚀 Projects Overview

Throughout the course, I developed several comprehensive projects that highlight different domains of computer science:

### [Project 1: Image Processing](Project/Project1)
* **Description:** Developed an image processing application. Implemented algorithms to manipulate pixel data, apply filters, and perform image transformations.
* **Skills:** Matrix operations, Data manipulation, Algorithm design.

### [Project 2: Sand Simulation](Project/Project2)
* **Description:** Built a falling sand particle simulation using object-oriented programming. Designed a grid-based physics engine handling different particle interactions and states.
* **Skills:** Object-Oriented Programming (OOP), State management, Simulation logic.

### [Project 3: Expression Calculator](Project/Project3)
* **Description:** Created a mathematical expression parser and calculator. This involved parsing complex expressions and evaluating them using appropriate data structures.
* **Skills:** Parsing algorithms, Data structures, Recursion.

### [Project 4: Web Crawler](Project/Project4)
* **Description:** Engineered a web crawler that systematically browses the internet to extract and process data. Implemented request safeguards to adhere to polite scraping practices.
* **Skills:** Network requests, Web scraping, Data extraction.

## 📚 Labs and Homework
